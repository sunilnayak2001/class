Class Notes
1. What is the Internet? (Simple Mental Model)
The internet is a global network of connected computers.


Think of it like a massive network of roads connecting millions of houses. Each house represents a computer or server.


When you open a website, your computer is talking to another computer somewhere in the world.


For example:


* You type a website address.
* Your browser sends a request.
* A server receives that request.
* The server sends back data.
* Your browser displays it.


This is called the client-server model.


Client = Your browser or app Server = The computer that stores and sends website data


Every website you visit follows this request–response model.


2. Addresses on the Internet: IP & Domain Names
Every computer connected to the internet has an IP address.


An IP address is a numeric address like: 192.168.1.1


But humans are not good at remembering numbers.


So we use domain names.


Example: google.com


A domain name is a human-friendly name for an IP address.


Now comes DNS.


DNS stands for Domain Name System.


DNS works like a phonebook of the internet.


When you type:


google.com


The browser asks DNS: “What is the IP address for google.com?”


DNS responds with the IP address.


Then your browser connects to that server.


Flow:


You type domain → DNS finds IP → Browser connects to server → Server responds.


3. HTTP vs HTTPS
HTTP stands for HyperText Transfer Protocol.


It is the basic method used to transfer web data.


When your browser talks to a server, it uses HTTP.


HTTPS is secure HTTP.


The “S” stands for Secure.


HTTPS ensures:


* Data is encrypted.
* Information cannot be easily stolen.
* Communication is protected.


Rule of thumb:


If a website handles:


* Login details
* Passwords
* Payments
* Personal data


It must use HTTPS.


Today, almost all professional websites use HTTPS.


4. What is a Web Browser?
A browser is the tool that allows you to access websites.


Examples include:


* Google Chrome
* Mozilla Firefox
* Microsoft Edge


A browser does three main things:


1. Sends a request to a server
2. Receives a response
3. Displays content on your screen


Websites are built using three main technologies:


HTML → Structure CSS → Styling JavaScript → Interaction


Think of a house:


HTML = walls and structure CSS = paint and decoration JavaScript = electricity and interactive devices


The browser reads these and renders the page.


The DOM (Document Object Model) is simply the structured version of the page that JavaScript can work with.


You do not need to go deeper right now.


5. What is Full-Stack Development?
Full stack development means building both frontend and backend parts of an application.


Frontend is what users see and interact with.


Frontend responsibilities include:


* UI screens
* Buttons
* Forms
* Input validation


Backend is what works behind the scenes.


Backend responsibilities include:


* Authentication
* Data storage
* Business logic
* APIs


Let us take a simple example: Login form.


Step 1: User enters email and password (frontend). Step 2: Frontend sends data to backend. Step 3: Backend checks credentials in the database. Step 4: Backend sends response (success or error). Step 5: Frontend displays result.


That entire flow is full stack.


If you understand both sides, you are a full stack developer.


6. Cloud Computing (Simple Understanding)
Earlier, companies had to buy physical servers and manage them.


Now, they rent computing power over the internet.


That is called cloud computing.


Cloud means:


Instead of owning machines, you rent them from companies like:


* Amazon Web Services (AWS)
* Microsoft Azure
* Google Cloud Platform (GCP)


Why cloud is used:


* It scales easily.
* It reduces upfront cost.
* It is accessible globally.
* It is reliable.


There are three broad service types:


IaaS – Rent virtual machines PaaS – Rent a platform to deploy apps SaaS – Rent ready-made software


You do not need technical depth now. Just understand the idea of renting computing resources.
